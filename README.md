# Shashank J — Software Engineering Portfolio

Personal software engineering portfolio showcasing full-stack projects, hackathon achievements, and campus leadership.

Built with **HTML5, Vanilla CSS3, and Vanilla JavaScript**.

## Features

### 1. Projects Showcase
- Displays engineering projects in a horizontal scroll track.
- Includes active live demo links and repository references.

### 2. Industry Credentials & Certifications
- Displays credentials in an auto-scrolling horizontal reel.
- Supports category filtering (AI, Hackathons, Full-Stack, Workshops).

### 3. Dynamic GitHub Data Integration
- Fetches live repository metrics and commit data from the GitHub REST API (`api.github.com/users/Shashankcodelover`).
- Computes language distribution percentages (JavaScript, TypeScript, Python, HTML/CSS).

### 4. Technical Skills
- Displays skill categories (Web & Backend Engineering, AI & Machine Learning, Databases) using UI progress rings.

### 5. Campus Involvement & Leadership
- Highlights active campus roles including Persona Plus PR team member, HACK-OLYMPIC 2026 organizing team volunteer, and Linux Campus Club volunteer.

## Getting Started

### Local Development

```bash
npx http-server ./ -p 8080 -c-1
```
The server starts at `http://localhost:8080`.
